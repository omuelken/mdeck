# आपके क्षेत्र के टूल *Python में लिखे गए हैं*।

:::notes
डेटा पर आधारित काम के लिए Python शिक्षा जगत और उद्योग, दोनों में सबसे प्रचलित भाषा है।
लाइफ़ साइंसेज़ भी अपवाद नहीं — बायोइन्फ़ॉर्मेटिक्स, इमेजिंग और क्लिनिकल डेटा विश्लेषण, सब Python पर चलते हैं।

इसका इकोसिस्टम (NumPy, Pandas, Matplotlib, scikit-learn, BioPython) बेजोड़ है।
बताएँ कि सांख्यिकी में R अब भी आम है, पर Python काफ़ी हद तक साझा भाषा बन चुकी है।

# वेरिएबल किसी मान का नाम है।
:::slot left
```python live editable copy
name = "E. coli"
genome_size = 4_641_652   # बेस पेयर
gc_content = 0.506        # अनुपात

print(name, genome_size, gc_content)
print(f"GC content: {gc_content:.1%}")
```
:::
:::slot right
कोई घोषणा नहीं: Python मान से ही टाइप पहचान लेता है।

**आज़माएँ:** `gc_content` को `0.65` कर दें और फिर से चलाएँ।
:::

:::notes
वेरिएबल बस किसी मान से जुड़ा एक नाम है। Python टाइप अपने-आप पहचान लेता है।

ध्यान दिलाएँ: न सेमीकोलन, न टाइप घोषणा, न अतिरिक्त ढाँचा। `f"…"` स्ट्रिंग किसी मान को टेक्स्ट के भीतर फ़ॉर्मैट करती है; `:.1%` अनुपात को प्रतिशत में दिखाता है।
छात्रों को मान बदलकर फिर से चलाने के लिए प्रोत्साहित करें — लाइव ब्लॉक का यही मक़सद है।

# चार टाइप से जीवविज्ञान का ज़्यादातर डेटा बन जाता है।

:::steps
- **`int`** — पूर्ण संख्याएँ: गिनती, स्थिति, इंडेक्स
- **`float`** — दशमलव संख्याएँ: सांद्रता, p-मान, फ़ोल्ड चेंज
- **`str`** — टेक्स्ट: जीन के नाम, सीक्वेंस, सैंपल ID
- **`bool`** — True या False: सार्थकता फ़्लैग, गुणवत्ता फ़िल्टर
:::

:::notes
एक बार में एक टाइप दिखाएँ और अगला दिखाने से पहले लैब से एक उदाहरण पूछें।

ज़ोर दें कि बूलियन आमतौर पर तुलना से आते हैं, सीधे लिखे True/False से नहीं। अगली स्लाइड पर पूरे कमरे से पूछा जाएगा।
:::

# स्ट्रिंग सीक्वेंस की तरह व्यवहार करती हैं।
:::slot left
```python live editable copy
dna = "ATGCGTAAGCTTGAC"

print("Length:     ", len(dna))
print("First codon:", dna[:3])
print("A count:    ", dna.count("A"))

print("As RNA:     ", dna.replace("T", "U"))
```

# लिस्ट मानों को क्रम में रखती है।
:::slot left
```python live editable copy
conc = [0.12, 0.45, 0.33, 0.78, 0.21]

print("Samples:", len(conc))
print("First:  ", conc[0])
print("Last:   ", conc[-1])
print("Sorted: ", sorted(conc))
print("Mean:   ", sum(conc) / len(conc))
```
:::
:::slot right
गिनती शून्य से शुरू होती है: `conc[0]` पहला आइटम है, `conc[-1]` आख़िरी।

**आज़माएँ:** छठा मान जोड़ें और देखें कि औसत कैसे बदलता है।
:::

:::notes
लिस्ट क्रम बनाए रखती है और दोहराए गए मान भी रख सकती है। इंडेक्स 0 से शुरू होता है। ऋणात्मक इंडेक्स अंत से गिनते हैं।
इनके लिए बढ़िया: टाइम सीरीज़, दोहराए गए माप, क्रम से होने वाले प्रोसेसिंग चरण।

आम ग़लती: छात्र पहले आइटम के लिए इंडेक्स 1 लेते हैं। 0 से इंडेक्सिंग शुरू में ही पक्की करवाएँ।

# `if` रास्ता चुनता है।
:::slot left
```python live editable copy
p_value = 0.023
fold_change = 2.4

if p_value < 0.05 and fold_change > 2:
    print("Significant upregulation")
elif p_value < 0.05:
    print("Significant, modest effect")
else:
    print("Not significant")
```
:::
:::slot right
इंडेंटेशन ही ब्लॉक है: Python ब्रेसेज़ नहीं, ख़ाली जगह का इस्तेमाल करता है।

**आज़माएँ:** `fold_change = 1.5` कर दें।
:::

:::notes
if / elif / else से हर तरह की शाखा बनती है। Python में इंडेंटेशन शैली की बात नहीं — यह सिंटैक्स है।
दूसरी भाषाओं या R से आए छात्र यहाँ अटकते हैं। कोलन और इंडेंट अनिवार्य हैं।
दिखाएँ कि कोलन भूलने पर क्या होता है: Python SyntaxError देता है।
:::

# `for` हर आइटम के लिए एक काम दोहराता है।
:::slot left
```python live editable copy
values = [1.2, 0.8, 2.1, 1.5, 0.9, 2.8]

above = []
for value in values:
    if value > 1.0:
        above.append(value)

print(len(above), "of", len(values))
print(above)
```
:::
:::slot right
लूप, जाँच, संग्रह: डेटा फ़िल्टर करने का मूल पैटर्न।

**आज़माएँ:** इसके बजाय 1.0 से छोटे मान गिनें।
:::

:::notes
for लूप किसी भी कलेक्शन पर चलते हैं। यह पैटर्न — लूप, जाँच, संग्रह — लगभग हर उस डेटा प्रोसेसिंग स्क्रिप्ट के केंद्र में है जो छात्र लिखेंगे।

**D** दबाएँ और स्लाइड पर एक मान को लूप में ट्रेस करें: `value` में, `if` से होकर, `above` में। Escape से ड्रॉइंग बंद होती है; ड्रॉइंग स्लाइड के साथ बनी रहती है।
:::

# फ़ंक्शन इनपुट को आउटपुट में बदलता है।
:::slot left
```python live editable copy
def gc_content(seq):
    """सीक्वेंस में GC का अनुपात लौटाता है।"""
    gc = seq.count("G") + seq.count("C")
    return gc / len(seq)

for seq in ["ATGCGC", "AATTAA", "GCGCGC"]:
    print(seq, f"{gc_content(seq):.0%}")
```
:::
:::slot right
इसे एक बार लिखें, फिर हर सैंपल पर बुलाएँ।

**आज़माएँ:** लिस्ट में अपना सीक्वेंस जोड़ें।
:::

:::notes
def, पैरामीटर, return — पूरा सिंटैक्स बस इतना है।
समझाएँ: एक बार परिभाषित करें, अलग-अलग इनपुट के साथ कई बार बुलाएँ।
docstring (def के बाद तीन उद्धरण चिह्नों वाली स्ट्रिंग) अच्छी आदत है — इसे जल्दी सिखाएँ।

# तीन लाइब्रेरी से लाइफ़ साइंसेज़ के ज़्यादातर काम हो जाते हैं।

इसलिए छात्र कम कोड लिखते हैं और शुद्ध Python लूप की तुलना में तेज़ और भरोसेमंद नतीजे पाते हैं।

# NumPy पूरे ऐरे पर गणना करता है।
:::slot left
```python live copy
import numpy as np

m = np.array([1.2, 0.8, 2.1, 1.5, 0.9, 2.8])

print("Mean:  ", m.mean().round(3))
print("Std:   ", m.std().round(3))
print("Median:", np.median(m))
print("> 1.5: ", m[m > 1.5])
```
:::
:::slot right
`m[m > 1.5]` बिना लूप के फ़िल्टर करता है।

इसकी तुलना दो अध्याय पहले वाले `for` लूप से करें।
:::

:::notes
NumPy के ऑपरेशन पूरे ऐरे पर एक साथ लागू होते हैं — कोई लूप नहीं। यह तेज़ भी है और पढ़ने में आसान भी।
इस वेक्टराइज़्ड शैली की आदत पड़ने में समय लगता है, पर इसे जल्दी सीखना फ़ायदेमंद है।
डेमो: चलाने से पहले छात्रों से अनुमान लगवाएँ कि `m > 1.5` क्या लौटाता है।
:::

# आगे क्या सीखें।

- **Pandas** — CSV लोड करना, पंक्तियाँ फ़िल्टर करना, समूहों के आँकड़े निकालना
- **Matplotlib और Seaborn** — स्कैटर प्लॉट, हीटमैप, वॉल्केनो प्लॉट
- **scikit-learn** — वर्गीकरण, क्लस्टरिंग, आयाम घटाना
- **BioPython** — सीक्वेंस, BLAST, GenBank और PDB फ़ाइलें

ख़ास तौर पर लाइफ़ साइंसेज़ के लिए: BioPython का दस्तावेज़ और Python for Bioinformatics पाठ्यपुस्तक (Bassi)।

# कोड लिखना सीखने का सबसे अच्छा तरीक़ा है *कोड लिखना*।

:::notes
इसी पर समापन करें। प्रोग्रामिंग एक कौशल है — इसमें अभ्यास लगता है। पहले कुछ हफ़्ते धीमे लगते हैं,
फिर बात बैठ जाती है। रोज़ अभ्यास के लिए प्रोत्साहित करें, चाहे छोटी स्क्रिप्ट ही क्यों न हों। अभ्यास-प्रश्नों की ओर इशारा करें।
:::
