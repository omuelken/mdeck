# ابزارهای رشتهٔ شما *با Python نوشته شده‌اند*.

:::notes
Python در دانشگاه و صنعت، زبان غالب برای کارهای داده‌محور است.
علوم زیستی هم استثنا نیست: بیوانفورماتیک، تصویربرداری و تحلیل داده‌های بالینی همه روی Python اجرا می‌شوند.

اکوسیستم آن (NumPy، Pandas، Matplotlib، scikit-learn، BioPython) بی‌رقیب است.
اشاره کنید که R هنوز در آمار رایج است، اما Python تا حد زیادی به زبان مشترک تبدیل شده است.
:::

# متغیر نامی برای یک مقدار است.
:::slot left
```python live editable copy
name = "E. coli"
genome_size = 4_641_652   # جفت باز
gc_content = 0.506        # کسر

print(name, genome_size, gc_content)
print(f"GC content: {gc_content:.1%}")
```
:::
:::slot right
بدون اعلان: Python نوع را از خود مقدار تشخیص می‌دهد.

**امتحان کنید:** `gc_content` را به `0.65` تغییر دهید و دوباره اجرا کنید.
:::

:::notes
متغیر فقط نامی است که به یک مقدار وصل شده. Python نوع را خودکار تشخیص می‌دهد.

یادآوری کنید: نه نقطه‌ویرگول، نه اعلان نوع، نه کد اضافی. رشتهٔ `f"…"` مقداری را درون متن قالب‌بندی می‌کند؛ `:.1%` کسر را به‌صورت درصد نشان می‌دهد.
دانشجویان را تشویق کنید مقادیر را تغییر دهند و دوباره اجرا کنند؛ هدف بلوک زنده همین است.

# چهار نوع، بیشتر داده‌های زیستی را پوشش می‌دهند.

:::steps
- **`int`** — اعداد صحیح: شمارش‌ها، موقعیت‌ها، اندیس‌ها
- **`float`** — اعداد اعشاری: غلظت‌ها، p-value، تغییرات چندبرابری
- **`str`** — متن: نام ژن‌ها، توالی‌ها، شناسهٔ نمونه‌ها
- **`bool`** — True یا False: پرچم معناداری، فیلترهای کیفیت
:::

:::notes
هر بار یک نوع را نشان دهید و پیش از نمایش بعدی، از تجربهٔ آزمایشگاهی دانشجویان مثالی بخواهید.

تأکید کنید که مقادیر بولی معمولاً از مقایسه به دست می‌آیند، نه از نوشتن مستقیم True/False. اسلاید بعدی از همهٔ کلاس می‌پرسد.
:::

# لیست مقادیر را به ترتیب نگه می‌دارد.
:::slot left
```python live editable copy
conc = [0.12, 0.45, 0.33, 0.78, 0.21]

print("Samples:", len(conc))
print("First:  ", conc[0])
print("Last:   ", conc[-1])
print("Sorted: ", sorted(conc))
print("Mean:   ", sum(conc) / len(conc))
```
:::
:::slot right
شمارش از صفر شروع می‌شود: `conc[0]` اولین عضو است و `conc[-1]` آخرین.

**امتحان کنید:** مقدار ششمی اضافه کنید و تغییر میانگین را ببینید.
:::

:::notes
لیست‌ها ترتیب را حفظ می‌کنند و مقدار تکراری را می‌پذیرند. اندیس از ۰ شروع می‌شود. اندیس‌های منفی از انتها می‌شمارند.
مناسب برای: سری‌های زمانی، اندازه‌گیری‌های تکراری، مراحل پردازش به ترتیب.

اشتباه رایج: دانشجویان برای اولین عضو اندیس ۱ را امتحان می‌کنند. اندیس‌گذاری از ۰ را زود جا بیندازید.

# `if` یک مسیر را انتخاب می‌کند.
:::slot left
```python live editable copy
p_value = 0.023
fold_change = 2.4

if p_value < 0.05 and fold_change > 2:
    print("Significant upregulation")
elif p_value < 0.05:
    print("Significant, modest effect")
else:
    print("Not significant")
```
:::
:::slot right
تورفتگی همان بلوک است: Python از فاصله استفاده می‌کند، نه از آکولاد.

**امتحان کنید:** `fold_change = 1.5` را قرار دهید.
:::

:::notes
if / elif / else همهٔ شاخه‌ها را پوشش می‌دهد. در Python تورفتگی سلیقه‌ای نیست؛ بخشی از نحو است.
دانشجویانی که از زبان‌های دیگر یا R می‌آیند اینجا گیر می‌کنند. دونقطه و تورفتگی اجباری‌اند.
نشان دهید اگر دونقطه را فراموش کنید چه می‌شود: Python خطای SyntaxError می‌دهد.
:::

# `for` یک کار را برای هر عضو تکرار می‌کند.
:::slot left
```python live editable copy
values = [1.2, 0.8, 2.1, 1.5, 0.9, 2.8]

above = []
for value in values:
    if value > 1.0:
        above.append(value)

print(len(above), "of", len(values))
print(above)
```
:::
:::slot right
حلقه، آزمون، جمع‌آوری: الگوی اصلی فیلتر کردن داده‌ها.

**امتحان کنید:** به جای آن، مقادیر کمتر از 1.0 را بشمارید.
:::

:::notes
حلقه‌های for روی هر مجموعه‌ای پیمایش می‌کنند. این الگو، یعنی حلقه، آزمون، جمع‌آوری، در قلب تقریباً هر اسکریپت پردازش داده‌ای است که دانشجویان خواهند نوشت.

کلید **D** را بزنید و یک مقدار را روی اسلاید در حلقه دنبال کنید: به `value`، از میان `if`، به `above`. Escape طراحی را متوقف می‌کند؛ نقاشی با اسلاید می‌ماند.
:::

# تابع ورودی‌ها را به خروجی تبدیل می‌کند.
:::slot left
```python live editable copy
def gc_content(seq):
    """کسر GC یک توالی را برمی‌گرداند."""
    gc = seq.count("G") + seq.count("C")
    return gc / len(seq)

for seq in ["ATGCGC", "AATTAA", "GCGCGC"]:
    print(seq, f"{gc_content(seq):.0%}")
```
:::
:::slot right
یک بار بنویسید، سپس آن را روی هر نمونه فراخوانی کنید.

**امتحان کنید:** توالی خودتان را به لیست اضافه کنید.
:::

:::notes
def، پارامترها، return: کل نحو همین است.
مرحله‌به‌مرحله توضیح دهید: یک بار تعریف کنید، بارها با ورودی‌های مختلف فراخوانی کنید.
docstring (رشتهٔ سه‌گیومه‌ای پس از def) روش درستی است؛ زود معرفی‌اش کنید.

# NumPy روی کل آرایه محاسبه می‌کند.
:::slot left
```python live copy
import numpy as np

m = np.array([1.2, 0.8, 2.1, 1.5, 0.9, 2.8])

print("Mean:  ", m.mean().round(3))
print("Std:   ", m.std().round(3))
print("Median:", np.median(m))
print("> 1.5: ", m[m > 1.5])
```
:::
:::slot right
`m[m > 1.5]` بدون حلقه فیلتر می‌کند.

آن را با حلقهٔ `for` دو فصل قبل مقایسه کنید.
:::

:::notes
عملیات NumPy به‌یک‌باره روی کل آرایه اعمال می‌شوند؛ بدون حلقه. هم سریع‌تر است و هم خواناتر.
عادت به این سبک برداری زمان می‌برد، اما ارزش دارد زود یاد گرفته شود.
نمایش: پیش از اجرا از دانشجویان بخواهید حدس بزنند `m > 1.5` چه برمی‌گرداند.
