## Tap on a picture

`<pinpoint>` is a new activity: the phones show a picture, people tap the spot, and the slide shows every tap as a dot on it. `answer="62% 31% 8%"` (or in the picture's pixels, `answer="412 230 40"`) names a circle: the tick draws it, counts the taps inside and tells each phone whether its tap hit. The eye hides the dots until you show them, as for a poll, and `mdeck results` writes each tap as `62.1% 31.4%`, with the summary counting on and off target.

Phones never load the deck, so the presenter's screen sends them the picture through the room server, made smaller (at most 1000 px and 190 KB, never as SVG). The server keeps it in memory only while the `<pinpoint>` is on screen.

Thanks to Oliver Mülken ([@omuelken](https://github.com/omuelken)) for the feature, written for his physics lectures.

Update your poll server too: a server from before this release cannot take the picture, and the phones keep waiting for it.
