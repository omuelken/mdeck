Presenting from an iPad on any network, and new names for commands, settings and files. Every old name stops with a message that names its replacement.

## Present from an iPad on any network

`mdeck run --server` presents from an iPad through your own `mdeck server`, without opening a port on your computer or hosting the deck. The server needs this version and a key in `MDECK_SERVER_KEY`.

## Renamed commands

- `mdeck dev` and `mdeck present` are `mdeck run`; `mdeck live` is `mdeck server`.
- `mdeck send` makes the file to send; `mdeck build --reader` makes a reader folder to host.
- `mdeck templates` and `mdeck extensions` are `mdeck list` and `mdeck starter`.

## Renamed settings and files

- `design` is `theme`; `pageNumbers`, `institution` and the like are under `show.`; `live.server` is `server`.
- Slide `note:` is gone; write a `:::notes` block.
- `<deck>.ink.json` is `<deck>.drawings.json`, `?view=share` is `?view=reader`, and `MDECK_LIVE_KEY` is `MDECK_SERVER_KEY`.
- `mdeck migrate` updates a deck (`--dry-run` to preview), and `mdeck check` reports old settings.
