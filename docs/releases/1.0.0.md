The first release.

## Writing

Slides in Markdown with YAML settings and speaker notes, seven layouts, six themes and eight palettes. `mdeck new` starts a deck, `mdeck check` checks it, `mdeck edit` opens a browser editor, and a skill lets Claude Code write slides.

## Presenting and sharing

- A presenter view with notes, a timer and an audience window.
- A reader view for the people you share the deck with, without your notes.
- Builds as a folder or one HTML file; `mdeck pdf` makes a PDF.
