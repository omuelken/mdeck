## Six built-in themes

`neue` (still the default), `academic` and `minimal`, and new `plain`, `work` and `glass`. `aurora` moved to the theme repository: a deck that uses it is told to run `mdeck themes install aurora`.

## Polls

- A poll's options can be a list inside the tag, with `- [x]` for a right answer.
- A `|` inside code or a link no longer splits an option, and text after `<poll … />` no longer goes missing.
