## Host your slides on your own server

`mdeck publish talk.md` puts the deck on your mdeck server and prints its link, `https://your.host/d/talk`: the reader view in one file, without speaker notes. A name that is taken is refused until `--replace` says to overwrite it, and `mdeck publish --name talk --remove` takes the deck down. Hosting is optional: a server accepts decks only when started with `mdeck server --decks <folder>`, and publishing needs its `MDECK_SERVER_KEY`. Opening a deck needs only the link, and nothing lists the decks, so a name that is hard to guess is a private link.

## A better server

`mdeck server` has a page at `/` with its version, the `server:` line for a deck and a status view of its rooms. `mdeck server --check <address>` tests a running server from outside, and the server warns about a key that is easy to guess.

## Pinpoint areas, maths and fixes

`<pinpoint answer="…">` takes rectangles and polygons, and several shapes at once. Inline maths next to other characters, such as `$x$-Achse`, shows again (#34), and `mdeck check` finds maths that would not show. A paired iPad now gets a pinpoint's picture and a theme installed for every deck.

Update your poll server too: a standalone server from before this release does not show the phones the new pinpoint shapes.
