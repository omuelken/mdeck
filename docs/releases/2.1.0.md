## Palettes, redone

Colours come only from palettes: nine families, each with a light and a dark variant, picked with `appearance: light` or `dark`. `accent` and `accent2` in decks are removed, as are the old palettes `paper`, `sage`, `mono` and the `dark-…` ones; `mdeck check` names replacements. Your own palettes need `[light]` and `[dark]` tables.

## Redesigned themes

neue (now Swiss style), aurora, duet, editorial and terminal are redesigned. PDFs and sent files carry the theme's own fonts.

## Drawing

- Fingers swipe and tap while the pencil draws.
- A laser pointer replaces the fading marker.
- Select, move and delete strokes; hold the pen still for a straight line.
- Two fingers zoom into a slide, and the audience window follows.

## Code

Long code shrinks, then scrolls, instead of running under the heading. Python packages such as `numpy` load before the code runs.
