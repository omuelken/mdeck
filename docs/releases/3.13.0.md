## Data on slides

`<data>` holds a table of numbers as CSV, in the slide or in a file beside the deck, and shows it as a table or, with `show="…"`, as a bar, line, scatter, stat, heatmap or dumbbell chart in the palette's colours. `mdeck check` says what is wrong with the data. Ways to show data are extensions (`dataview`) you can write yourself.
