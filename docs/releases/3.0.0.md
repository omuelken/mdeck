## Fewer built-in themes

`duet`, `editorial`, `fhnw`, `terminal` and `sketch`, and the palettes `ember`, `forest` and `graphite`, moved to the theme repository. A deck that uses one gets an error naming the command to run, such as `mdeck themes install duet`. Files made with `mdeck send` or `mdeck build` keep working.

## Themes come in packs

Built-in themes can be removed (`mdeck themes remove aurora`) and installed again offline. `mdeck themes install` now installs for every deck; `--local` installs beside the deck.

## New theme `minimal`

Nothing but the content, in the computer's own fonts, so it works offline. Its palette is the new `paper`.
