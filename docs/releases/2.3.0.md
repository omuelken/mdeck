## mdeck moved to GitHub and npm

Install it with `npm install -g mdeck`; the docs are at <https://gh.tschieber.de/mdeck/>. Remove the old package with `npm uninstall -g @tilman.schieber/mdeck`.

## Themes from the theme repository

`mdeck themes search` and `mdeck themes install <pack>` fetch themes and palettes, for one deck or with `--global` for every deck.

## Design page

`mdeck design` shows themes and palettes on a sample deck or your own, and lets you fine-tune a copy. In `mdeck edit` it is **Design themes**. Layouts are no longer edited in the browser.
