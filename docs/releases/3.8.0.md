## Zoom into part of a slide

With `hotspots: auto`, the presenter view numbers each picture, code block, table or formula on a slide, and **1**–**9** zoom into it on every screen. **H** turns hotspots on or off during the talk.

## One talk in several languages

Write one file per language, `talk.en.md` and `talk.de.md`. The presenter view gets a **Language** switch (**L**) that changes slides and notes in every window, at the same slide.

## Right-to-left languages

Decks in Farsi, Arabic or Hebrew (`lang: fa` …) run from right to left in every theme; code and maths stay left to right.
