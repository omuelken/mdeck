## Themes and palettes install one by one

Packs are gone. `mdeck themes install duet` installs a theme with its default palette, `mdeck palettes install solarized` a palette. Each carries its version and the mdeck it needs in its own `extension.toml`; `pack.toml` is gone.

## Before you update

- mdeck 3.0 cannot read the theme repository any more; update to install themes.
- The palettes `graphite` and `ember` are gone; a deck that names one is told what to use instead.
